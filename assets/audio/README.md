# Kooperatif Vikipedi Podcast Ses Dosyaları Dizini

Bu dizin, Google NotebookLM Studio "Sesli Genel Bakış (Audio Overview)" üzerinden üretilen `.mp3` veya `.wav` podcast kayıtlarının yerleştirildiği alandır.

### Dosya İsimlendirme Formatı:
- `bolum_1.mp3` : Bölüm 1 - 7511 Sayılı Kanun Sonrası Anasözleşme İntibakı ve Fesih Riskleri
- `bolum_2.mp3` : Bölüm 2 - KOOPBİS Veri Girişi, Mali Tablo Yükleme ve Hapis Cezaları
- `bolum_3.mp3` : Bölüm 3 - Dış Denetim Zorunluluğu, SBDS 2400 ve 2026 E-Genel Kurul
- `bolum_4.mp3` : Bölüm 4 - Ortaklıktan Çıkarılma (İhraç), Dava Süreçleri ve Parasal Haklar
- `bolum_5.mp3` ... ve sonraki bölümler.

Dosyalar buraya eklendiğinde `articles/34_gunluk_kooperatif_podcast_yayini.md` içerisindeki HTML5 oynatıcı otomatik olarak ilgili ses dosyasını çalacaktır.
Eğer ses dosyası henüz eklenmemişse, yerleşik Web Speech API Türkçe ses motoru senaryoyu anında sesli okumaktadır.
